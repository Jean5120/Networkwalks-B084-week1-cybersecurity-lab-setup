## 📌 Project Overview

This project involves developing a **virtual cybersecurity and penetration-testing lab** using VirtualBox and Kali Linux.

The goal is to establish a controlled testing environment in which cybersecurity tools and techniques, such as network scanning, reconnaissance, vulnerability assessment and security testing, can be practised safely and consistently.

The lab operates on a dedicated private virtual network, providing the flexibility to introduce additional virtual machines in the future and use them as targets for authorized security assessments.

---

## 🎯 Project Objectives

The primary objectives of this project are to:

- Install and set up VirtualBox.
- Import and configure Kali Linux as a virtual machine.
- Set up a private **NAT Network** for the lab environment.
- Establish network connectivity within Kali Linux.
- Configure a consistent IP address for the Kali virtual machine.
- Test network communication and confirm DNS resolution.
- Create an initial VM snapshot to support system recovery.
- Document the installation and configuration procedures.
- Establish a foundation for future practical cybersecurity projects.

---

## 🛡️ Lab Purpose

The purpose of this lab is to provide a dedicated and isolated environment for hands-on cybersecurity training, experimentation and authorized penetration testing.

It creates an opportunity to develop practical skills and explore various security techniques, including:

- Network reconnaissance and information gathering.
- Network discovery and port scanning.
- Vulnerability identification and assessment.
- Practical use of Kali Linux security tools.
- Network configuration and connectivity testing.
- Exploration of ethical hacking and penetration-testing methodologies.
